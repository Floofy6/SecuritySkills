# Generic Agentic Source Mapping

This fixture represents a report that maps an architecture finding to an AG
identifier without recording the current OWASP Agentic Applications source.

```text
Finding: AG01 excessive agency
Framework source: OWASP GenAI Security Project
Source URL: https://genai.owasp.org
Release label: not recorded
Date checked: not recorded
Category naming status: unknown
Mapping confidence: claimed high
```

The mapping should be treated as an evidence gap until the report records the
current OWASP source URL, release label, date checked, and category naming
status.
